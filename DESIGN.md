# Mac-Monologue — Design

A native macOS talking-head recorder. Pick a camera and a mic once, press Space,
talk, press Space to pause, `⌘↩` to finish — the file lands in `~/Movies/Monologue`.

A fork of [omacom/monologue](https://github.com/omacom/monologue) — David
Heinemeier Hansson's Qt 6 webcam recorder for Omarchy, MIT licensed — in
provenance rather than in code. The upstream implementation is preserved
untouched on the `master` branch.

**Not a port.** The Linux original spends much of its code on problems macOS does
not have: it bypasses Qt's audio layer to talk to libpulse directly just to obtain
trustworthy capture timestamps, and it shells out to `ffmpeg` to finalize each take.
On macOS, `AVCaptureSession` delivers camera and microphone buffers on one
synchronized clock, and `AVAssetWriter` writes a faststart-optimized file itself.
The original is the specification; none of it is the implementation.

## Scope

Camera + microphone only. No screen capture in v1.

Built for two people — the author and one friend — which is the justification for
several decisions below that would be wrong for a product with real users.

## Decisions

### Platform & build

- Swift 6.4 + SwiftUI; AVFoundation for capture; hardware HEVC encode via VideoToolbox.
- Xcode project generated by **XcodeGen** from `project.yml`. The `.xcodeproj` is gitignored.
- **arm64 only.** Both target machines are Apple Silicon.
- **Zero runtime dependencies.** No ffmpeg, no Homebrew, no frameworks to install.
  The `.app` is self-contained.

### Identity

- Display name **Mac-Monologue**; bundle ID **`io.github.alexanderpuschkinberlin.mac-monologue`**.
- Public repository, MIT licensed.
- Generated flat `.icns` icon at all required resolutions.

### Capture

- Format chosen automatically: the best camera format **capped at 1080p30**.
  No resolution UI; the chosen format is shown in the status pill.
- **HEVC + AAC in `.mp4`**, average bitrate **10 Mbps**,
  `shouldOptimizeForNetworkUse = true` — this replaces the original's ffmpeg
  `+faststart` remux, with no second pass and no external binary.
- Filename `Monologue-yyyy-MM-dd-HHmmss.mp4`, matching the original's convention.

### Pause / resume — the load-bearing feature

- `AVAssetWriter` + `AVCaptureVideoDataOutput` / `AVCaptureAudioDataOutput`, **not**
  `AVCaptureMovieFileOutput`, which has no pause API at all.
- Pause is accumulated-offset arithmetic on presentation timestamps: paused intervals
  are subtracted, so one continuous file comes out with the dead air removed.
  This is conceptually the original's `TakeClock`.
- That math lives in a pure `TakeClock` struct with no AVFoundation import. It is the
  only part of the app that gets unit tests.

### Storage

- Record to a temp file; **move into `~/Movies/Monologue/` on Finish.** A crash or a
  discard therefore leaves nothing behind in a folder the user looks at.
- No staging library, no `take.json` manifests, no Recordings browser — all removed
  relative to the original.
- Discard after finishing moves the file to **Trash**, not `unlink`, so Finder's
  Put Back works.
- The original's "Open in Omacut" becomes **Reveal in Finder** (`⇧⌘R`).

### UI

- Standard resizable window, normal title bar and traffic lights, preview letterboxed,
  sensible minimum size. Follows system light/dark. No theme syncing.
- Two device pickers, remembered by **unique device ID** in `UserDefaults`. A remembered
  device that has disappeared is shown greyed as `<name> — unavailable` rather than
  silently falling back to another camera. The microphone list includes an explicit
  **"No audio"**. Both pickers lock for the whole take, including while paused.
- **Microphone meter replicated in full**: −60…0 dB scale, peak-hold, red clipping
  indicator; live from launch and while paused; never monitored through the speakers.
- Seven states: `needsAccess` · `unavailable` · `ready` · `recording` · `paused` ·
  `finishing` · `preview`. `finishing` is a real state, not a spinner — the HEVC flush
  is not instant, and keystrokes during it are how a file gets corrupted.
- Shortcuts: **Space** record → pause → resume (play/pause in preview) · **`⌘↩`** finish ·
  **`⌫`** discard (always confirms, with the confirm button focused) · **`⇧⌘R`** reveal ·
  **`⌘N`** new · **`⌘Q`** quit · **`?`** help.
  `Esc` stays reserved for dismissing dialogs, departing from the original's Esc-to-discard.
- Menu bar: App · File (New, Reveal) · Recording (Record/Pause, Finish, Discard) · Window · Help.

### Failure behavior

- Permission denied or absent → `needsAccess` pill with a button that opens the
  Camera/Microphone pane of System Settings directly.
- **Device disconnects mid-take → stop, finalize, keep the partial file, show a banner.**
  Not an edge case: Continuity Camera drops every time the iPhone locks.
- Explicitly **not** in v1: crash recovery for interrupted takes.

### Distribution

- Self-signed code-signing certificate — a stable identity, so camera and microphone
  grants survive rebuilds.
- **No provisioning profile. Sandbox off. Hardened runtime off. Not notarized.**
- Recipient flow: unzip → double-click → System Settings → Privacy & Security →
  **Open Anyway** (once) → grant camera and microphone (once). Nothing else.

## Layout

```
project.yml                    XcodeGen
Sources/MacMonologue/
  App.swift                    @main, single window
  ContentView.swift            pickers · preview · controls · meter
  CameraPreviewView.swift      NSViewRepresentable → AVCaptureVideoPreviewLayer
  CaptureController.swift      AVCaptureSession, devices, permissions
  TakeRecorder.swift           AVAssetWriter, HEVC settings, temp → Movies move
  TakeClock.swift              pure pause-interval math  ← the unit-tested part
  AudioLevelMeter.swift        RMS + peak-hold + clipping from sample buffers
  DevicePreferences.swift      UserDefaults: last camera / microphone IDs
Tests/MacMonologueTests/       TakeClock, filename, format selection
```

## Build order

1. `xcode-select` to Xcode, `brew install xcodegen`, `git init`.
2. `project.yml` + Info.plist usage strings → an app that launches and shows an empty window.
3. `CaptureController`: device enumeration, permissions, live preview.
   **First milestone: you see yourself.**
4. `TakeRecorder` start/stop only, no pause → a playable file in `~/Movies/Monologue`.
5. `TakeClock` + tests, then wire pause/resume into the writer.
6. Meter, preview-after-take, discard/confirm, menu bar, shortcuts.
7. Icon, self-signed release build, hand it over.

## Accepted trade-offs

- **HEVC** is the one choice with a cost outside the two target Macs: a Windows
  recipient or a strict upload target may balk. An H.264 toggle is a small later addition.
- **No crash recovery** means a hard crash mid-take loses that take entirely — the
  temp file is incomplete and unplayable.
- **Self-signed and un-notarized** means every fresh download needs the Open Anyway
  step, including for the author.
